Política de Privacidade

1. Sobre esta Política de Privacidade

Esta Política de Privacidade tem como objetivo informar como o Organizador Acadêmico coleta, utiliza, armazena e protege os dados fornecidos pelos usuários durante a utilização do sistema.

2. Dados coletados

O Organizador Acadêmico poderá coletar informações necessárias para a criação da conta e para o funcionamento de suas funcionalidades, como nome, e-mail, senha, instituição de ensino, curso, CEP da instituição, cidade e estado.

Também poderão ser armazenadas informações acadêmicas cadastradas pelo próprio usuário, como semestres, disciplinas, atividades, avaliações, notas, prazos e status das atividades.

3. Finalidade do tratamento dos dados

Os dados coletados serão utilizados para possibilitar o funcionamento do Organizador Acadêmico, incluindo a criação e identificação da conta, autenticação do usuário, preenchimento do perfil acadêmico e organização de semestres, disciplinas, atividades, avaliações, notas e prazos.

As informações também poderão ser utilizadas para manter o sistema funcionando de forma adequada, realizar validações e oferecer ao usuário uma visualização organizada de sua rotina acadêmica.

4. Armazenamento e segurança

Os dados do Organizador Acadêmico serão armazenados em banco de dados PostgreSQL, utilizando o Supabase como serviço de hospedagem e gerenciamento dessas informações.

As senhas dos usuários não serão armazenadas em texto puro. O sistema utiliza BCrypt para gerar o hash das senhas, além de aplicar validações e mecanismos de controle de acesso para aumentar a segurança das informações.

5. Serviços de terceiros

O Organizador Acadêmico utiliza serviços de terceiros para viabilizar algumas de suas funcionalidades e sua infraestrutura, como Supabase para banco de dados, Render para hospedagem do backend, GitHub Pages para publicação do frontend e ViaCEP para consulta de informações relacionadas ao CEP da instituição de ensino.

A utilização desses serviços ocorre apenas quando necessária para o funcionamento do sistema, de acordo com a finalidade de cada recurso.

6. Compartilhamento de dados

O Organizador Acadêmico não tem como finalidade vender ou comercializar os dados pessoais dos usuários. As informações poderão ser tratadas por serviços utilizados na infraestrutura do sistema somente quando isso for necessário para o funcionamento das funcionalidades oferecidas.

O acesso às informações deverá ocorrer de forma limitada às finalidades do sistema e respeitando as medidas de segurança e privacidade adotadas pelo projeto.

7. Tempo de armazenamento

Os dados dos usuários serão mantidos enquanto forem necessários para a manutenção da conta e para o funcionamento das funcionalidades do Organizador Acadêmico.

Quando os dados deixarem de ser necessários, poderão ser removidos de acordo com as funcionalidades disponibilizadas pelo sistema e com as regras aplicáveis ao tratamento de dados pessoais.

8. Direitos do usuário

O usuário poderá solicitar acesso às informações relacionadas à sua conta, bem como a correção ou atualização de dados incorretos ou desatualizados.

Também poderá solicitar a exclusão de seus dados pessoais, observadas as condições necessárias para o funcionamento do sistema e as regras aplicáveis de proteção de dados.

9. Alterações da Política de Privacidade

Esta Política de Privacidade poderá ser atualizada sempre que houver mudanças relevantes nas funcionalidades do Organizador Acadêmico, no tratamento dos dados pessoais ou nos serviços utilizados pelo sistema.

A versão mais recente desta Política de Privacidade permanecerá disponível no sistema para consulta dos usuários.
