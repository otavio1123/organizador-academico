Política de Privacidade

1. Sobre esta Política de Privacidade

Esta Política de Privacidade tem como objetivo informar como o Organizador Acadêmico coleta, utiliza, armazena e protege os dados pessoais fornecidos pelos usuários durante a utilização do sistema.

O tratamento dos dados pessoais busca garantir o funcionamento das funcionalidades da aplicação, a segurança das contas e a organização das informações acadêmicas cadastradas pelos próprios usuários.

2. Dados coletados

Para criação e utilização da conta, o Organizador Acadêmico coleta informações como nome e endereço de e-mail.

A senha cadastrada pelo usuário também é utilizada para autenticação, porém não é armazenada em texto puro. O sistema mantém apenas o hash da senha gerado por meio do BCrypt.

Também são armazenadas informações relacionadas ao aceite dos Termos de Uso, incluindo a confirmação do aceite, a data e hora em que ele ocorreu e a versão dos Termos aceita pelo usuário.

Durante a utilização do sistema, poderão ser armazenados dados acadêmicos cadastrados pelo próprio usuário, como semestres, disciplinas, atividades, avaliações, notas, prazos e demais informações necessárias à organização da rotina acadêmica.

Para o processo de recuperação de senha, o sistema também poderá armazenar temporariamente informações necessárias à validação do código de recuperação, como o identificador do usuário, o hash do código, a data de criação, a data de expiração, o número de tentativas e a informação de utilização do código.

3. Finalidade do tratamento dos dados

Os dados pessoais são utilizados para permitir a criação e identificação da conta, autenticação do usuário, recuperação e alteração de senha e utilização das funcionalidades do Organizador Acadêmico.

Os dados acadêmicos cadastrados pelo usuário são utilizados para possibilitar a organização de semestres, disciplinas, atividades, avaliações, notas, prazos e demais informações relacionadas à sua rotina acadêmica.

As informações relacionadas ao aceite dos Termos de Uso são armazenadas para registrar quando o aceite ocorreu e qual versão dos Termos estava disponível naquele momento.

Os dados relacionados à recuperação de senha são utilizados somente para validar a solicitação e permitir a redefinição segura da senha da conta.

4. Armazenamento e segurança

Os dados do Organizador Acadêmico são armazenados em banco de dados PostgreSQL utilizando o Supabase como serviço de banco de dados.

As senhas dos usuários não são armazenadas em texto puro. O sistema utiliza BCrypt para gerar hashes seguros das senhas antes de seu armazenamento.

Após a autenticação, o sistema utiliza token JWT para identificar o usuário nas funcionalidades protegidas. As requisições privadas devem apresentar autenticação válida para serem processadas.

O backend realiza verificações para que o usuário tenha acesso apenas às informações relacionadas à própria conta. Identificadores enviados pelo frontend não são utilizados como única forma de determinar a propriedade dos dados.

As credenciais de banco de dados, chaves de APIs externas e demais segredos utilizados pelo sistema são mantidos em variáveis de ambiente e não devem ser armazenados diretamente no código-fonte ou disponibilizados publicamente no repositório do projeto.

5. Recuperação de senha

O Organizador Acadêmico disponibiliza uma funcionalidade de recuperação de senha por meio de código de verificação enviado ao endereço de e-mail cadastrado.

O código possui validade limitada e não é armazenado em texto puro. O sistema armazena somente o hash utilizado para sua validação.

Também são aplicados controles de tentativas e de solicitações para reduzir o risco de uso indevido da funcionalidade de recuperação de senha.

Após a utilização válida do código, ele não poderá ser reutilizado.

6. Serviços de terceiros

O Organizador Acadêmico utiliza serviços de terceiros necessários ao funcionamento de determinadas funcionalidades.

O Supabase é utilizado para hospedagem e gerenciamento do banco de dados PostgreSQL do sistema.

A Resend é utilizada para o envio de e-mails relacionados à recuperação de senha. Nesse processo, o endereço de e-mail do usuário e o conteúdo necessário ao envio da mensagem poderão ser tratados pelo serviço.

A integração com esses serviços ocorre somente quando necessária para o funcionamento das funcionalidades correspondentes.

7. Compartilhamento de dados

O Organizador Acadêmico não tem como finalidade vender ou comercializar os dados pessoais de seus usuários.

Alguns dados poderão ser tratados por serviços utilizados na infraestrutura da aplicação, como Supabase e Resend, quando isso for necessário para fornecer as funcionalidades do sistema.

O tratamento dessas informações deve ocorrer de forma limitada às finalidades apresentadas nesta Política de Privacidade.

8. Tempo de armazenamento

Os dados relacionados à conta e às informações acadêmicas serão mantidos enquanto forem necessários para a utilização e o funcionamento do Organizador Acadêmico.

Informações temporárias utilizadas para recuperação de senha serão mantidas somente pelo período necessário para controle e validação da solicitação, conforme as regras de segurança definidas pelo sistema.

Quando uma conta for excluída, os dados vinculados serão tratados de acordo com as regras de exclusão e retenção adotadas pelo projeto e com as necessidades técnicas aplicáveis.

9. Direitos do usuário

O usuário poderá acessar informações relacionadas à própria conta e solicitar a correção de dados pessoais que estejam incorretos ou desatualizados, conforme as funcionalidades disponibilizadas pelo sistema.

O usuário também poderá alterar sua senha e solicitar a exclusão da própria conta.

A exclusão da conta será realizada após a confirmação da identidade do usuário, por meio de autenticação e confirmação da senha atual.

O usuário poderá consultar a Política de Privacidade e os Termos de Uso disponibilizados pelo Organizador Acadêmico a qualquer momento por meio das páginas acessíveis dentro do sistema.

10. Controle de acesso aos dados

As funcionalidades privadas do Organizador Acadêmico exigem autenticação válida.

O sistema utiliza o token de autenticação para identificar o usuário responsável pela requisição e verificar o acesso às informações vinculadas à sua conta.

Um usuário não deverá conseguir consultar, alterar ou excluir dados pertencentes a outro usuário por meio da alteração de identificadores enviados na URL, no corpo da requisição ou pelo frontend.

11. Alterações desta Política de Privacidade

Esta Política de Privacidade poderá ser atualizada sempre que houver mudanças relevantes nas funcionalidades do Organizador Acadêmico, no tratamento dos dados pessoais ou nos serviços utilizados pelo sistema.

Quando houver alterações relevantes, a versão da Política poderá ser atualizada para representar as novas condições de tratamento dos dados.

A versão mais recente desta Política de Privacidade permanecerá disponível no sistema para consulta dos usuários.

Última atualização: 24 de setembro de 2026.
